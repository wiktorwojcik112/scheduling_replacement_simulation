# Scheduling and Replacement Simulation
This is a project that simulates a few scheduling and replacement algorithms.

Scheduling:
- SRTF
- SJF
- FCFS

Replacement:
- LRU
- FIFO

It can be used in two modes: CLI, GUI.

CLI can be used by running "python main.py" with appropriate arguments.

GUI can be started by running "python gui/simulator.py".
